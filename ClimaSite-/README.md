# ClimaSite - Site Institucional para Empresa de Ar Condicionado

## Visão Geral

Projeto de desenvolvimento de site institucional completo para empresa de prestação de serviços de ar condicionado. O objetivo é estabelecer presença online profissional, atrair novos clientes via SEO local e centralizar informações de serviços e portfólio.

## Escopo do Projeto

### Páginas
- **Página Inicial** - Hero, serviços em destaque, CTA
- **Serviços** - Instalação, manutenção, limpeza, etc.
- **Portfólio** - Cards de projetos realizados com fotos reais
- **Sobre Nós** - História, equipe, diferenciais
- **Contato** - Formulário + botão WhatsApp

### Funcionalidades
- Design responsivo (mobile-first)
- SEO local otimizado para cidade/região de atuação
- Painel administrativo para atualização de conteúdo sem programação
- Formulário de contato funcional
- Botão de WhatsApp flutuante
- Google Meu Negócio integrado

### Identidade Visual
- Cores: Azul e branco
- Logotipo incluído no escopo
- Design moderno e profissional

## Stack Sugerida

| Camada | Tecnologia |
|--------|-----------|
| Frontend | HTML5 / CSS3 / JavaScript |
| CMS | Painel administrativo simples |
| Hospedagem | A definir (orientação incluída no escopo) |
| SEO | On-page + Google Meu Negócio |

## Prazo

**10 a 12 dias** após confirmação do contrato.

## Estratégia de SEO Local

- Palavras-chave: `instalação de ar condicionado + [cidade]`, `manutenção de ar condicionado + [região]`
- Configuração de Google Meu Negócio
- Meta tags, títulos e descrições otimizados por página
- Schema markup para empresa local

## Portfólio

A seção de portfólio é o principal elemento de conversão. Cada card incluirá:
- Foto real do projeto instalado
- Tipo de equipamento (split, multi-split, central, etc.)
- Tipo de ambiente (residencial, comercial, industrial)
- Breve descrição

O cliente será orientado na organização e seleção do conteúdo fotográfico existente.
